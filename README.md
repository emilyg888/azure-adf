# Fabric Foundry

Metadata-driven data platform framework for Microsoft Fabric and Databricks.

This repository contains:

- Fabric pipelines, notebooks, and environment definitions.
- Databricks job, bundle, and cluster policy scaffolding.
- Shared framework modules for metadata, ingestion, transforms, targets, governance, and audit.
- Metadata DDL, seed examples, and data contracts.
- Agent prompts and generated asset locations.
- CI/CD pipeline placeholders.
